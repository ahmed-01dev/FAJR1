# فَجْر — FAJR

تطبيق إسلامي عربي لعرض مواقيت الصلاة، الأذكار، ومتابعة العبادات اليومية والإنجازات الشخصية، مع ميزات اجتماعية اختيارية (الصحبة والفرق) عند إعداد Firebase.

## الميزات المنفذة فعليًا

- **مواقيت الصلاة:** حساب محلي عبر مكتبة `adhan` — يعمل دون إنترنت، مع دعم 5 طرق حساب و2 مذهب للعصر.
- **الصفحة الرئيسية:** تحية حسب الوقت، الصلاة التالية مع عدّاد المتبقي، مواقيت اليوم كاملة.
- **الأذكار:** أذكار الصباح والمساء والنوم من **حصن المسلم** مع مرجع كل ذكر، عداد تكرار، حفظ التقدم محليًا، إلغاء التسجيل، وتصفير العداد.
- **التهيئة الأولى:** اختيار المدينة (22 مدينة) وطريقة الحساب والمظهر والاسم.
- **الوضع الفاتح/الداكن/تلقائي:** ثيم هادئ بألوان أخضر عميق وذهبي دافئ، RTL كامل.
- **العمل دون إنترنت:** كل الوظائف الأساسية محلية بالكامل.

## ما هو جاهز ويحتاج إعدادًا خارجيًا فقط

- **الحسابات والصحبة والفرق:** قواعد Firestore صارمة + دوال خادم (TypeScript) جاهزة — تُفعَّل بإنشاء مشروع Firebase (انظر `docs/firebase-setup.md`).
- **توقيع Release حقيقي:** الخطوات في `docs/release.md`.

## التقنيات

Flutter Stable + Dart 3 (Null Safety) · Material 3 · RTL عربي كامل · `adhan` للمواقيت · `shared_preferences` للتخزين · Firebase (خامل حتى الإعداد)

## التشغيل

```bash
flutter pub get

```

## الاختبار

```bash
flutter analyze
flutter test
```

التفاصيل وما لم يُغطَّ بعد: `docs/testing.md`

## بناء APK

```bash
flutter build apk --release
```

أو من CI: تبويب **Actions** ← تشغيل ناجح ← **Artifacts** ← `fajr-release-apk`.

## حالة الميزات بصدق

| الميزة | الحالة |
|---|---|
| مواقيت الصلاة (محلي، 5 طرق، مذهبان) | ✅ منفذة ومُختبرة |
| الأذكار + عداد + مراجع | ✅ منفذة ومُختبرة |
| الإعدادات (ثيم/مدينة/طريقة/مذهب/أرقام) | ✅ منفذة ومُختبرة |
| الاختبارات (مواقيت، إعدادات، أخطاء، محتوى) | ✅ موجودة |
| شاشة بدء مقيدة (لا تحميل لانهائي) | ✅ منفذة |
| Android كامل (Gradle، Manifest، Themes) | ✅ منفذة |
| CI (تحليل + اختبار + APK Artifact) | ✅ مُعرَّفة |
| قواعد Firestore + دوال الخادم | ✅ مكتوبة — تنتظر مشروع Firebase |
| اختبارات Widgets/تكامل | ⏳ غير موجودة بعد |
| إشعارات محلية مُجدولة | ⏳ الصلاحيات جاهزة، الجدولة تنتظر التنفيذ |
| الصحبة والفرق (واجهات) | ⏳ تنتظر Firebase |
