# فَجْر — FAJR

تطبيق إسلامي عربي لعرض مواقيت الصلاة، الأذكار، ومتابعة العبادات اليومية والإنجازات الشخصية، مع ميزات اجتماعية اختيارية (الصحبة والفرق) عند إعداد Firebase.

## الميزات المنفذة

- **مواقيت الصلاة:** حساب محلي عبر مكتبة `adhan` — يعمل دون إنترنت، مع دعم طرق حساب متعددة.
- **الصفحة الرئيسية:** تحية، تاريخ محلي وهجري، الصلاة التالية والوقت المتبقي، تقدم اليوم، اختصارات سريعة.
- **الأذكار:** أذكار الصباح والمساء والنوم من مصادر موثقة مع عداد تكرار وحفظ التقدم محليًا.
- **الإنجازات:** تتبع أهداف شخصية اختيارية بلا لغة تأنيب.
- **الصحبة والفرق:** واجهات جاهزة تُفعَّل عند إعداد Firebase.
- **الوضع الفاتح/الداكن:** ثيم هادئ بألوان أخضر عميق وذهبي دافئ.
- **العمل دون إنترنت:** كل الوظائف الأساسية تعمل محليًا بالكامل.

## التقنيات

- Flutter (Stable) + Dart 3 مع Null Safety
- Material 3 مع دعم RTL كامل
- Firebase (Auth, Firestore, Functions, Messaging) — غير مُفعّل حتى الإعداد
- `adhan` لحساب المواقيت، `shared_preferences` للإعدادات والتقدم
