# الاختبارات

## الأوامر

```bash
flutter pub get        # تثبيت الاعتمادات
dart format .          # تنسيق الكود
flutter analyze        # التحليل الثابت
flutter test           # كل الاختبارات
flutter test --coverage  # مع تقرير تغطية
```

## ملفات الاختبار الحالية

| الملف | ما يغطيه |
|---|---|
| `test/prayer_calculator_test.dart` | ترتيب المواقيت، المذهبين، طرق الحساب، الصلاة التالية (قبل الفجر، بين الصلوات، بعد العشاء)، تنسيق المتبقي |
| `test/settings_test.dart` | القيم الافتراضية، copyWith، round-trip، fallback من القيم الفاسدة |
| `test/app_error_test.dart` | تحويل الاستثناءات لأنواع مصنفة، Result wrapper |
| `test/adhkar_data_test.dart` | سلامة بيانات الأذكار: تكرار المعرفات، وجود المرجع، عدم فراغ الأقسام |

## قراءة النتائج

- نجاح: `All tests passed!` مع عدد الاختبارات.
- فشل: تظهر التفاصيل مع سطر الفشل وسبب `expect`.
- الاختبارات تعمل دون إنترنت ودون Firebase — كلها منطق محلي خالص.

## حدود التغطية الحالية (بصدق)

- اختبارات Widgets (شاشات فعلية) واختبارات تكامل لم تُكتب بعد — مُخطَّطة للإصدار التالي.
- اختبارات قواعد Firestore تتطلب Firebase Emulator Suite (غير متاح في CI الحالي).
- التغطية الحالية مركزة على المنطق الحرج: المواقيت والإعدادات والأخطاء وسلامة المحتوى.
